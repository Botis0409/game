# Cercul — demo site

Investor demo of **Cercul**, a reading game for 3rd graders (Fry sight words): every sentence on screen is an instruction — read it, then do it.

- Presentation page: https://ticketing-platform.online/
- Playable build (Unity WebGL): https://ticketing-platform.online/play/
- Gameplay video: `media/cercul-demo.mp4` (full level) · `media/cercul-trailer.mp4` (52 s cut)
- Thumbnail: `media/thumbnail.jpg` (1280×720) · `media/thumbnail-1920.jpg`

The game itself is built in Unity 6 (URP); this repository only holds the published site.
